# 集客専用LP：15分の無料オンライン動画

Instagram・Meta広告から訪れる方に向けた専用ページです。

## ページの場所

- 公式ホームページ：ルートの `index.html`。従来のデザインとURLを維持しています。
- 集客専用LP：`lp/index.html`。

GitHub Pagesでこの変更を公開した後のLP URLは、`https://souchan558877.github.io/my-first-app/lp/` です。ファイルを作成しただけでは公開サイトは更新されません。

## まず表示を確認する

ダウンロードしたファイルでは、`lp` フォルダを開き、`index.html` をChrome・Edge・Safariで開いてください。CSS・JavaScript・とびらの画像はHTML内に埋め込み済みです。公式ホームページは、LP最下部の「公式ホームページへ」から開けます。

開発サーバーはリポジトリのルートで起動します。

```sh
cd /workspace/my-first-app
python3 -m http.server 8000 --bind 0.0.0.0
```

開発環境のポート8000のプレビューを開いた後、URLの末尾に `lp/` を追加するとLPです。ルートのURLが公式ホームページです。クラウド側のlocalhostには、自分のパソコンから直接接続できません。

## LPだけを編集する

| 内容 | 編集するファイル |
| --- | --- |
| キャッチコピー・紹介文・セクション構成 | `lp/index.html` |
| LPの色・余白・文字サイズ・スマートフォン表示 | `lp/styles.css` |
| 申し込み先・申し込みボタンの動作 | `lp/script.js` |
| LPのとびらの画像 | `lp/assets/door.svg` |

公式ホームページのCSS・JavaScript・画像とは共有していません。LPの変更で公式ホームページの見た目や申し込み先は変更されません。

CSS・JavaScript・画像を変更したら、以下を実行してLPのHTMLを更新してください。本文はそのまま保持され、公式ホームページには触れません。

```sh
python3 lp/build_preview.py
```

## 正式な申し込み先URLを設定する

現在はURL未設定です。**すべての申し込みボタンが無効で、仮のリンク・申し込みフォーム・メール送信はありません。** 「準備中」の案内も表示しています。指定の「15分の無料動画で公開中！」というコピーは配置済みですが、受付を開始するには正式なURLの設定が必要です。

1. `lp/script.js` を開きます。
2. `const APPLICATION_URL = '';` の引用符の間に、正式なHTTPSの申し込み先URLを入れます。
3. `python3 lp/build_preview.py` を実行します。
4. LPをブラウザで再読み込みします。
5. 申し込みボタンが有効になり、準備中の表示が受付ページへの案内に変わります。ボタンは同じタブで正式な申し込み先を開きます。

空欄・不正なURL・HTTPS以外のURLでは有効になりません。申し込み先のサービス・視聴方法・個人情報の取り扱いは、実際の受付内容に合わせて案内を調整してください。現時点では解析タグや広告ピクセルも追加していません。
